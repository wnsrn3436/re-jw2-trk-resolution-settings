# 더랭커 해상도 패치

Setting.exe 는 함께 배포한 `trk.ex_` 를 새 이름으로 복사한 뒤, 그 안의 데이터 몇 군데를 고쳐 해상도와 인터페이스 위치를 바꾼다. `trk.ex_` 는 쥬라기원시전2: 더랭커의 실행 파일로, 해상도와 인터페이스 좌표를 데이터에서 읽도록 코드가 고쳐져 있다. 고친 자리는 `NOP`(`0x90`) 으로 채운 구간으로 남아 있다.

주소는 전부 가상 주소다. 이미지 베이스는 `0x400000` 이고 `.data` 섹션은 가상 주소 `0x700000` 이 파일 오프셋 `0x300000` 이라, 파일 오프셋은 가상 주소에서 `0x400000` 을 뺀 값이다. Setting.exe 도 모든 주소에서 4194304(`0x400000`)를 빼서 파일 위치를 정한다.


## 해상도

화면 너비와 높이는 `0x143FFF0` 과 `0x1440004` 에 있고 `0x407416` 에서 두 변수에 800 과 600 을 넣는다.

```
C7 05 F0 FF 43 01 20 03 00 00    mov dword ptr [0x143FFF0], 800
C7 05 04 00 44 01 58 02 00 00    mov dword ptr [0x1440004], 600
```

`trk.ex_` 의 `0x4D6E97` 은 `0x8635CC` 와 `0x8635C8` 의 값을 읽어 두 변수에 넣고 그 값을 인자로 `0x4F4060` 함수를 부른다. 읽기와 쓰기 사이 `0x4D6EA3` 부터 `0x4D6EDC` 까지는 `NOP` 이다.

```
8B 15 CC 35 86 00    mov edx, [0x8635CC]
8B 1D C8 35 86 00    mov ebx, [0x8635C8]
90 ...               nop
89 15 CC 34 73 00    mov [0x7334CC], edx
89 1D D0 34 73 00    mov [0x7334D0], ebx
89 15 F0 FF 43 01    mov [0x143FFF0], edx
89 1D 04 00 44 01    mov [0x1440004], ebx
E8 ...               call
FF 35 EC FF 43 01    push [0x143FFEC]
FF 35 04 00 44 01    push [0x1440004]
FF 35 F0 FF 43 01    push [0x143FFF0]
FF 35 6C FF 43 01    push [0x143FF6C]
E8 49 D1 01 00       call 0x4F4060
```

Setting.exe 는 `0x8635CC` 에 너비를, `0x8635C8` 에 높이를 쓴다. 두 주소는 `DB.dat` 의 첫 두 줄이다.


## 인터페이스 좌표 표

화면 아래 인터페이스의 좌표는 `0x8635C8` 부터 시작하는 표에 있다. `0x4E2BD3` 의 코드가 `ecx * 0x60 + 종족 * 0x18` 위치에서 좌표를 읽는데 종족 번호는 `0x725C04` 에 있다.

```
2B C9                   sub ecx, ecx
41                      inc ecx
90 ...                  nop
89 0D 88 35 86 00       mov [0x863588], ecx
6B C1 60                imul eax, ecx, 0x60
6B 1D 04 5C 72 00 18    imul ebx, [0x725C04], 0x18
03 C3                   add eax, ebx
A3 10 5C 72 00          mov [0x725C10], eax
8B 90 C8 35 86 00       mov edx, [eax+0x8635C8]
8B 98 CC 35 86 00       mov ebx, [eax+0x8635CC]
```

`trk.ex_` 에서는 이 함수가 `0x4E2BB7` 에서 `ecx` 를 1 로 정하고 시작한다. 그래서 표는 언제나 `0x60 + 종족 * 0x18` 자리부터 읽히고 `ecx` 가 0 일 때의 칸인 `0x8635C8` 과 `0x8635CC` 가 해상도를 두는 곳이 된다. 같은 `ecx` 값은 `0x863588` 에 저장되어 `0x4E2FA2` 처럼 다른 표를 읽는 코드에서도 쓰인다.

`DB.dat` 의 주소 54개는 이 표의 기준 주소로, 두 줄이 한 쌍이고 앞 줄이 y, 뒤 줄이 x 다. `0x8635C8` 에서 `0x138` 씩 떨어진 9개 묶음에 3쌍씩 있다.

| 묶음 | 기준 주소 (y, x) |
|---|---|
| 1 | `0x8635CC, 0x8635C8` `0x8635D4, 0x8635D0` `0x8635DC, 0x8635D8` |
| 2 | `0x863704, 0x863700` `0x86370C, 0x863708` `0x863714, 0x863710` |
| 3 | `0x86383C, 0x863838` `0x863844, 0x863840` `0x86384C, 0x863848` |
| 4 | `0x863974, 0x863970` `0x86397C, 0x863978` `0x863984, 0x863980` |
| 5 | `0x863AAC, 0x863AA8` `0x863AB4, 0x863AB0` `0x863ABC, 0x863AB8` |
| 6 | `0x863BE4, 0x863BE0` `0x863BEC, 0x863BE8` `0x863BF4, 0x863BF0` |
| 7 | `0x863D1C, 0x863D18` `0x863D24, 0x863D20` `0x863D2C, 0x863D28` |

## Setting.exe 가 고치는 값

해상도를 `W x H` 로 고르면 `xpos = W - 800`, `ypos = H - 600` 을 구한다. 800x600 기준의 좌표에서 y 에는 `ypos` 를, x 에는 `xpos / 2` 를 더해 인터페이스를 화면 아래 가운데로 옮긴다.

| 주소 | 값 | 고치는 방법 |
|---|---|---|
| `0x8635CC`, `0x8635C8` | 너비, 높이 | `W`, `H` 를 쓴다 |
| `DB.dat` 의 주소 + `0x60 + 0x18 * 종족` (종족 0 부터 3) | 인터페이스 좌표 표 | y 에 `ypos`, x 에 `round(xpos / 2)` 를 더한다 |
| `0x8640A8`, `0x8640AC` | x, y | `19 + round(xpos / 2)`, `518 + ypos` 를 쓴다. `0x4E5C48` 에서 읽는다 |
| `0x8635A0` 부터 4개 | 종족별 값 | `ypos` 를 더한다. `0x4E2CF7` 에서 화면 높이에서 뺀다 |
| `0x8642DC + 16`, `0x8642E0 + 16` | x, y | x 에 `round(xpos / 2)`, y 에 `ypos` 를 더한다 |
| `0x8642E4 + 16`, `0x8642E8 + 16` | x, y | 위와 같다 |
| `0x864314 + 8`, `0x864318 + 8` | x, y | 위와 같다 |
| `0x86444C`, `0x864450` + `8 * n` (n 은 16 부터 31) | x, y 16쌍 | 위와 같다 |
| `0x864170`, `0x864174` + `8 * n` (n 은 14 부터 27) | x, y 14쌍 | 위와 같다 |
| `0x864354`, `0x864358` + `8 * n` (n 은 5 부터 9) | x, y 5쌍 | 위와 같다 |
| `0x8645FC`, `0x864600` + `8 * n` (n 은 6 부터 11) | x, y 6쌍 | 위와 같다 |
| `0x8646C4`, `0x8646C8` + `8 * n` (n 은 7 부터 13) | x, y 7쌍 | 위와 같다 |

`+ 16` 과 `+ 8 * n` 은 모두 `ecx` 가 1 일 때의 칸이다. `0x4E2FA2` 는 `ecx` 를 4비트 밀어 `0x8642DC` 표를 읽으므로 한 칸이 16바이트이고, 개수가 n 개인 표는 n 번째 쌍부터가 `ecx` 1 의 칸이다.


## 메모의 다른 주소

작업 메모에 남은 주소 중 위에서 다루지 않은 것이다.

| 주소 | 메모 | 확인한 내용 |
|---|---|---|
| `0x4D284D` | 해상도 | `push 600`, `push 800` 바로 뒤의 `push [0x143FF6C]` 다. 같은 `0x4F4060` 함수를 800 과 600 상수로 부르는 자리다 |
| `0x4E02A5` | 인터페이스 그리기 | `0x4E02A0` 의 함수가 부르는 함수 네 개 중 두 번째 호출이다 |
| `0x4E2F98` | 1인 그림 | `0x4E2F8E` 부터 `0x4E2FA1` 까지의 `NOP` 구간 안이다 |
| `0x420580` | 포그 | `0x7071A8` 과 `0x7071AC` 를 읽는 함수의 시작이다. Setting.exe 는 이 함수를 고치지 않는다. 1024x768 을 넘는 해상도의 포그 표시가 추가 확인 대상이다 |
| `0x7071A8` | x 뷰 | |
| `0x863598` | x 뷰 최댓값 | |
